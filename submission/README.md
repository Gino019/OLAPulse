# Final submission links

This directory includes a **template only**. The links do not exist until you publish the repository, deployment, article and video.

Edit `links_template.txt` to use actual verified public URLs, then run:

```bash
python scripts/make_submission.py
```

The script creates `submission/OLAPulse_submission_links.zip` only after all placeholders have been replaced. Send the article and video links to the Telegram group and upload the ZIP to your class assignment.
